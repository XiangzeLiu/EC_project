SC三端结构图样式对比

Static Diagram Style Samples

同一个三端结构，六种静态画法

所有样例表达相同关系，不使用 Mermaid。这里只比较视觉风格、结构清晰度和文字容纳能力。

Client → SM：HTTPS 登录并取得 TS 地址 Client → TS：WSS 行情与交易 SM ↔ TS：注册审批、配置同步和心跳
01

简洁架构卡片

HTML + CSS Grid
操作端Client 登录、行情、持仓、下单与撤单
HTTPS 登录
管理端SM 账号、审批、域名和配置
WSS 行情与交易
执行端TS 券商连接与统一交易服务
文字容量最大，位置固定，最容易适配文档和移动端。
02

角色泳道图

HTML + CSS Swimlane
Client
输入交易员账号
取得 Token 与 TS 地址
建立 WSS 连接
展示行情与订单状态
SM
验证账号
返回绑定节点
接收 TS 心跳
TS
同步券商配置
验证并接受连接
上报状态与心跳
最适合解释“谁在什么时候做什么”，比拓扑图更贴近操作流程。
03

扁平 SVG 架构图

原生 SVG，位置完全固定
结构最精确，箭头和文字位置可逐像素调整，不存在自动布局重叠。
04

D2 现代架构风

预生成 SVG 的视觉参考
现代、规整、技术感适中，适合正式架构文档，但需要生成步骤。
05

Graphviz 拓扑风

自动拓扑布局的视觉参考
适合服务拓扑和端口关系，风格正式，但对非技术人员略显工程化。
06

手绘白板风

Rough.js / Excalidraw 风格参考
亲和、容易理解，适合培训和概念说明，但正式生产手册可能不够严肃。
